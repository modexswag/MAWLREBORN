## 🚨 БЕЛЫЙ ЭКРАН? ЧИТАЙ СЮДА! 👇

### Проблема: Вы загружаете не тот файл!

**❌ НЕ ЗАГРУЖАЙТЕ:**
- `index.html` из корня
- Папку `src/`
- Ничего кроме `dist/index.html`

**✅ ЗАГРУЖАЙТЕ:**
- Только `dist/index.html`

---

## 🎯 Два способа (выберите один)

### Способ 1: АВТОМАТИЧЕСКИЙ (рекомендую!)

```bash
# 1. Откройте терминал в папке проекта

# 2. Выполните команды:
git init
git add .
git commit -m "Modex Wallet"
git remote add origin https://github.com/ВАШ_USERNAME/ВАШ_REPO.git
git push -u origin main

# 3. На GitHub:
#    - Откройте ваш репозиторий
#    - Settings → Pages
#    - Source → выберите "GitHub Actions"
#    - Save

# 4. Подождите 3 минуты
# 5. Откройте: https://ВАШ_USERNAME.github.io/ВАШ_REPO/
```

**Готово! Сайт работает!** 🎉

---

### Способ 2: РУЧНОЙ

```bash
# 1. Соберите проект:
npm install
npm run build

# 2. Возьмите файл:
#    dist/index.html

# 3. Загрузите этот файл на хостинг

# 4. Откройте в браузере
```
