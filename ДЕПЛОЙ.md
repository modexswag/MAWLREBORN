2. Build command: `npm run build`

## 🔧 Решение проблем

### "Белый экран"
- Проверьте консоль браузера (F12)
- Убедитесь что загрузили `dist/index.html`, а не `index.html` из корня

### "Cannot find module"
- Это нормально для исходников
- Загружайте только `dist/index.html`

### "localStorage не работает"
- Нужен HTTPS или http://localhost
- На file:// может не работать

### На GitHub Pages не работает
- Убедитесь что в `vite.config.ts` есть `base: './'`
- Проверьте что Actions успешно выполнились
- Подождите 2-3 минуты после деплоя
