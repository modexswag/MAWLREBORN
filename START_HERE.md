# 🎯 НАЧНИТЕ ЗДЕСЬ

## ✨ Что добавлено (последнее обновление)

### 1. ✅ Username система
- **Нельзя создать username < 5 символов** бесплатно
- **Короткие username** (4 и меньше) - только через MDX Market
- **Проверка уникальности** - нельзя занять уже существующий username
- **Одноразовая покупка** - username с маркета можно купить только 1 раз

### 2. ✅ Глобальный чат 💬
- Общение между пользователями
- **Автоудаление через 24 часа** (не нагружает систему)
- Отображение префиксов
- До 500 символов в сообщении

### 3. ✅ Мультиаккаунт для админов 🔄
- Админ может **войти на 2 аккаунта одновременно**
- Кнопка "Switch Account"
- Быстрое переключение между сессиями

### 4. ✅ Деплой без папок 📦
- **Весь сайт в 1 файле** (`dist/index.html`)
- Легко загрузить на GitHub/хостинг
- Нет ошибок с путями

## ✅ Проверка перед деплоем

```bash
# 1. Установка
npm install

# 2. Сборка
npm run build

# 3. Проверка
ls -lh dist/index.html
# Должно быть ~340 KB
```

**Если все ОК:**
- ✅ Файл создан
- ✅ Размер правильный
- ✅ Можно деплоить!

## 🐛 Если что-то не так

### Ошибки при сборке
```bash
rm -rf node_modules dist
npm install
npm run build
```

### Не работает на хостинге
- Загружайте `dist/index.html`, НЕ `index.html` из корня
- Проверьте что используете HTTPS

### localStorage не работает
- Нужен HTTPS или localhost
- file:// может не работать
