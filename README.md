# 💼 Modex Wallet - Криптовалютный кошелек

Современный криптовалютный кошелек с полным функционалом управления цифровыми активами, NFT подарками и Premium подпиской.

## 🌟 Основные возможности

### 💰 Кошелек
- 9 криптовалют (BTC, ETH, SOL, TON, ADA, XRP, DOT, DOGE, USDT)
- Отображение балансов и портфеля
- История транзакций

### 👤 Профиль
- Настраиваемый аватар (25+ вариантов)
- Username с возможностью изменения
- Номера телефонов (+7 и +888)
- Premium статус с эмодзи в нике

### 🛒 MDX Market
- Покупка номеров телефонов
- Покупка premium юзернеймов
- NFT подарки (Common, Rare, Epic, Legendary)
- Оплата через TON

### 🎁 NFT Подарки
- 8 уникальных подарков
- Система улучшений
- Бонусы за уровни
- Коллекционирование

### 🎒 Инвентарь
- Хранение купленных номеров
- Хранение юзернеймов
- Быстрая смена активных предметов

### 💸 Переводы
- Отправка криптовалюты по username
- История переводов
- Логирование всех операций

### 💬 Глобальный чат
- Общение между пользователями
- Автоудаление сообщений через 24 часа
- Отображение префиксов
- До 500 символов в сообщении

### ⭐ Premium подписка
- Эмодзи в username
- Префиксы перед ником
- Эксклюзивный статус
- Особые возможности

### 👤 Система username
- Минимум 5 символов для бесплатных
- Короткие username (4 и менее) - только через маркет
- Проверка на уникальность
- Username с маркета можно купить только 1 раз

### 🔧 Админ-панель
- Управление NFT подарками
- Добавление товаров в маркет
- Выдача Premium подписки
- Управление ролями (User/Moderator/Admin)
- Выдача префиксов

## 🚀 Деплой

### Вариант 1: Один файл (Самый простой!)
```bash
npm install
npm run build
# Загрузите dist/index.html куда угодно - это весь сайт!
```

**Преимущества:**
- ✅ Один файл - весь сайт
- ✅ Никаких папок и зависимостей
- ✅ Работает на любом хостинге
- ✅ Можно открыть локально в браузере

### Вариант 2: GitHub Pages (Автодеплой)
1. Создайте репозиторий на GitHub
2. Загрузите код
3. В Settings → Pages → Source выберите "GitHub Actions"
4. При каждом push в main ветку сайт автоматически обновится

### Вариант 3: Netlify/Vercel
Просто загрузите папку `dist/` или подключите GitHub репозиторий

## 🛠️ Установка и запуск локально

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```
