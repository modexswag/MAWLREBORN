# 🔧 Исправление белого экрана

## ❗ Главная причина

**Вы загружаете НЕ ТОТ файл!**

### ❌ НЕ ПРАВИЛЬНО:
- Загружать `index.html` из корня проекта
- Загружать файлы из папки `src/`
- Загружать `node_modules/`

### ✅ ПРАВИЛЬНО:
Загружать **ТОЛЬКО** `dist/index.html`

---

## 🎯 Пошаговое решение

### Шаг 1: Соберите проект

```bash
# В терминале в папке проекта:
npm install
npm run build
```

**Результат:** Создастся папка `dist/` с файлом `index.html`

### Шаг 2: Найдите правильный файл

```
modex-wallet/
├── src/           ❌ НЕ ЗАГРУЖАТЬ
├── dist/          ✅ ВОТ ОТСЮДА!
│   └── index.html ✅ ЭТОТ ФАЙЛ!
├── index.html     ❌ НЕ ЭТОТ!
└── package.json   ❌ НЕ ЗАГРУЖАТЬ
```

### Шаг 3: Загрузите на хостинг

**Только файл `dist/index.html`!**

---

## 🌐 Для разных хостингов

### GitHub Pages

**Вариант A (Автоматический - РЕКОМЕНДУЮ):**
```bash
# Загрузите ВСЕ файлы проекта на GitHub
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main

# В Settings → Pages → Source: "GitHub Actions"
# GitHub сам соберет и задеплоит
```

**Вариант B (Ручной):**
```bash
# 1. Соберите
npm run build

# 2. Создайте новый репозиторий
# 3. Загрузите ТОЛЬКО dist/index.html
# 4. В Settings → Pages → Source: main branch
```

### Netlify

1. Перейдите на https://app.netlify.com/drop
2. Соберите: `npm run build`
3. Перетащите папку `dist/` (ВСЮ ПАПКУ!)
4. Готово!

### Обычный хостинг (FTP)

1. Соберите: `npm run build`
2. Откройте папку `dist/`
3. Загрузите `index.html` в корень сайта (обычно `public_html/`)

## 🐛 Если всё равно белый экран

### 1. Откройте консоль браузера

Нажмите `F12` → вкладка `Console`

**Видите ошибки?**

#### "Failed to load module"
→ Вы загрузили НЕ собранный файл
→ Загрузите `dist/index.html`

#### "Unexpected token '<'"
→ Проблема с путями
→ Используйте GitHub Pages с автодеплоем

### 2. Проверьте что загрузили

**Откройте файл который загрузили**

Если видите:
```html
<script type="module" src="/src/main.tsx"></script>
```

❌ Это НЕ ПРАВИЛЬНО! Это исходный файл!

Должно быть:
```html
<script type="module" crossorigin>
(function(){const V=document.createElement...
```

✅ Это правильно! Это собранный файл!

### 3. Проверьте размер файла

```bash
# В терминале:
ls -lh dist/index.html
```

**Должно быть:** ~340 KB (339-340 килобайт)

Если меньше → файл не тот!

## 🚀 Самый надежный способ

### GitHub Pages с автодеплоем:

```bash
# 1. Создайте репозиторий на GitHub

# 2. В терминале:
git init
git add .
git commit -m "Modex Wallet"
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main

# 3. На GitHub:
# Settings → Pages → Source: "GitHub Actions" → Save

# 4. Подождите 2-3 минуты

# 5. Откройте:
# https://YOUR_USERNAME.github.io/YOUR_REPO/
```

**Преимущества:**
- ✅ GitHub сам собирает проект
- ✅ Не нужно вручную собирать
- ✅ Автообновление при git push
- ✅ Никаких проблем с путями

---

## 📱 Проверка что работает

После деплоя должны увидеть:

✅ Форму входа/регистрации
✅ Логотип 💼
✅ Фиолетовый градиент
✅ Кнопки "Вход" и "Регистрация"

НЕ должны видеть:

❌ Белый экран
❌ Код JavaScript
❌ "import { StrictMode }"
❌ Ошибки в консоли
